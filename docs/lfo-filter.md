# LFO и фильтр основного осциллятора

Оба блока работают в звуковом ядре стенда (AudioWorklet) — в той же событийной модели 556,
поэтому LFO двигает **сами** VR1/VR2, а не готовый звук: делитель N и ступени пересчитываются на лету.

```
556 (VR1, VR2) ─► C3 (ФВЧ выхода) ─► Filter ─► tanh ─► Delay ─► выход
      ▲   ▲                            ▲
      └───┴──────────── LFO ───────────┘   (одна цель на выбор)
```

## LFO
| Контрол | Диапазон | CC |
|---|---|---|
| Rate | 0.05 … 20 Гц (экспоненциально) | 22 |
| Depth | 0 … 100 % (квадратичная кривая — точнее на малых значениях) | 23 |
| Форма | синус, треугольник, меандр, пила вниз, Sample & Hold | — |
| Куда | VR1 · Pitch, VR2 · Step, Cutoff фильтра | — |
| Перезапуск с каждой нотой | фаза LFO обнуляется на Note On | — |

- **VR1 / VR2**: сопротивление умножается на 2^(±2·depth²) — до ±2 октав по сопротивлению.
  На VR1 это вибрато/сирена, на VR2 — «дыхание» делителя N (ступени сами собой).
- **Cutoff**: срез умножается на 2^(±5·depth²) — до ±5 октав (wah, «квакание» с резонансом).
- Индикатор рядом с заголовком мигает в такт LFO (когда звук включён и Depth > 0).

## Filter
Двухполюсный фильтр с переменным состоянием (TPT SVF, 12 дБ/окт), стабилен на любой частоте среза.

| Контрол | Диапазон | CC |
|---|---|---|
| Cutoff | 30 Гц … 20 кГц (экспоненциально) | 20 |
| Resonance | Q 0.5 … 20 | 21 |
| Тип | Low-pass, Band-pass (пик 0 дБ), High-pass, Выключен | — |

- После фильтра стоит мягкое ограничение tanh, чтобы резонанс не перегружал вход Delay.
- График под ручками — АЧХ фильтра; при LFO → Cutoff пунктиром показан диапазон качания.

## MIDI
Все четыре ручки назначаются через **Learn** рядом с ними; назначения и настройки сохраняются в браузере.
Сводная таблица CC — в `docs/midi.md`.
