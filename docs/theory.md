# Принцип работы и расчёт

**Таймер A — астабильный.** VR1 + R1 заряжают C1 от ⅓ до ⅔ Vcc, разряд идёт только через R1 (1 кОм) в выв. 1.
Поэтому низкий уровень на выв. 5 — короткая «иголка» t_L = 0.693·R1·C1 ≈ 6.9 мкс.

- t_H = 0.693·(VR1 + R1)·C1
- T_A = t_H + t_L,  f_A = 1.44 / ((VR1 + 2·R1)·C1)
- Диапазон при C1 = 10 нФ: ≈ 287 Гц (VR1 = 500k) … ≈ 72 кГц (VR1 = 0)

**Таймер B — ждущий.** Иголка на выв. 8 (ниже ⅓ Vcc) запускает импульс:

- T_M = 1.1·VR2·C2  (C2 = 100 нФ → до 55 мс; C2 = 10 нФ → до 5.5 мс)

Пока идёт импульс, новые запуски игнорируются. Следующий импульс стартует по первому запуску после окончания текущего:

- N = ⌊T_M / T_A⌋ + 1
- f_OUT = f_A / N,  скважность = T_M / (N·T_A)

Отсюда «ступени»: при плавном повороте VR2 частота прыгает f_A, f_A/2, f_A/3 …

**Выход.** C3 10 мкФ на динамик 8 Ом образует ФВЧ ≈ 2 кГц (тихий, «звенящий» звук);
на линейном выходе (10k + 4.7k) срез ≈ 1 Гц. Реальный NE556 даёт высокий уровень ≈ Vcc − 1.7 В.

**Защита.** Когда VR1 или VR2 в нуле, выв. 1/13 (разрядный транзистор) замыкает +9 В почти напрямую.
В оригинале этого не учли; ставьте RS = 220–330 Ом последовательно с потенциометрами.
