# MIDI-управление стендом (ветка `midi`)

Стенд `apc.html` можно играть с MIDI-клавиатуры, с экранной клавиатуры или с клавиатуры компьютера.
Это управление **моделью** в браузере; на плату MIDI пока не заведён.

## Как подключить
1. Откройте `apc.html` в **Chrome, Edge или Firefox** (Safari не поддерживает Web MIDI).
   Во встроенном окне Claude доступ к MIDI может быть закрыт — тогда открывайте файл из папки.
2. Нажмите **S1 · Включить звук**, затем **Подключить MIDI** и разрешите доступ.
3. Выберите вход (или «Все входы») и канал (Omni — любой).

Без MIDI-устройства: ряд клавиш `A W S E D F T G Y H U J K O L P ;` (коды клавиш, работает в любой раскладке),
`Z` / `X` — октава ниже / выше. Экранная клавиатура показывает две октавы.

## Режимы «Что делает нота»
| Режим | Нота | CC «VR2» | Особенности |
|---|---|---|---|
| Ноты · ровный строй | подбирает VR1 **и** VR2 | скважность 2–95 % (тембр) | Строй точный от ≈ 17 Гц до 4 кГц+ (C2 = 100 нФ). Ниже ≈ 290 Гц скважность автоматически растёт до 1 − 1/N: так устроен APC — деление на N возможно только при длинном импульсе. |
| Ноты · как железо | подбирает только VR1 | VR2 напрямую | Крутите VR2 при зажатой ноте — классические ступени. Если импульс длиннее периода ноты, нота недостижима, стенд пишет ошибку в центах. |
| Только гейт | открывает звук | VR2 | Высоту задают VR1/VR2 (ручки или CC). |

Математика подбора: для периода ноты P нужно целое N и T_A = P/N, такие что ⌊T_M/T_A⌋ + 1 = N,
то есть скважность T_M/P ∈ [1 − 1/N, 1). Отсюда VR1 = T_A/(0.693·C1) − 2·R1 (− R_S).

## Контроллеры
| Действие | CC по умолчанию | Примечание |
|---|---|---|
| VR1 · Pitch | 74 | В режимах «Ноты» действует только без зажатой ноты |
| VR2 · Step / скважность | 1 (mod wheel) | Квадратичная кривая ≈ логарифмический A500K |
| Громкость | 7 | |
| All Notes Off | 120, 123 | Сброс зависших нот |
| Delay: Time / Feedback / Tone / Wow / Mix | 12 / 13 / 14 / 15 / 91 | см. `docs/delay.md` |
| Delay вкл./выкл. | 80 | ≥ 64 — вкл. |
| Delay Freeze | 64 (педаль сустейна) | пока ≥ 64 |

**Learn**: нажмите Learn у параметра и покрутите нужную ручку на контроллере. Назначения и настройки
запоминаются в браузере (localStorage).

- Pitch bend: ±2 или ±12 полутонов.
- Приоритет последней ноты (монофония): отпустили верхнюю — звучит предыдущая зажатая.
- «Звук только пока нажата нота» включается сам при первой ноте; выключите, чтобы стенд гудел постоянно.

## Ограничения
- Вариант Mims (C2 = 10 нФ): T_M ≤ 5.5 мс, ноты ниже ≈ 117 Гц недостижимы.
- Модель идеальная: реальный 556 даст отклонения ±10–15 % из-за допусков C1/C2.
