# Atari Punk Console — классическая схема

Ступенчатый генератор тона Форреста Мимса (1980) на сдвоенном таймере NE556, вариант Kaustic Machines.

## Содержимое папки
| Файл | Что внутри |
|---|---|
| `apc.html` | Интерактивный стенд (звук, осциллограммы, карта ступеней), схема, перечень элементов, контрольные точки. Открывается в любом браузере, работает офлайн (без интернета — системные шрифты). |
| `docs/schematic.svg` | Принципиальная схема (вектор) |
| `docs/schematic.png` | Принципиальная схема (растр, для печати) |
| `docs/bom.csv` | Перечень элементов для таблиц / закупки (разделитель `;`) |
| `docs/netlist.txt` | Список соединений + соответствие выводов 556 ↔ 2 × 555 |
| `docs/theory.md` | Принцип работы и формулы |
| `docs/test-procedure.md` | Первое включение, контрольные точки, поиск неисправностей |
| `docs/sources.md` | Источники |

## Перечень элементов (кратко)
| Поз. | Номинал | Кол. | Примечание |
|---|---|---|---|
| U1 | NE556 / LM556, DIP-14 (+ панелька) | 1 | или 2 × NE555 |
| VR1 | 500 кОм лин. (B500K) | 1 | частота |
| VR2 | 500 кОм лин. (B500K) | 1 | ступени; часто ставят A500K |
| R1 | 1 кОм | 1 | R_B астабильного |
| C1 | 10 нФ | 1 | таймер A |
| C2 | 100 нФ (Mims: 10 нФ) | 1 | таймер B |
| C3 | 10 мкФ 16 В | 1 | выход |
| LS1 | 8 Ом 0.25–0.5 Вт | 1 | |
| BT1, S1 | 9 В + клипса, SPST | 1+1 | |
| опц. RS1, RS2 | 330 Ом | 2 | защита выв. 1/13 |
| опц. C4, C5 | 100 нФ, 10–100 мкФ | 1+1 | развязка питания |
| опц. R3, R4, J1 | 10 кОм, 4.7 кОм, моно-гнездо | 1+1+1 | линейный выход |
| опц. D1, R5 | LED, 1 кОм | 1+1 | индикатор |

## Главные формулы
- f_A = 1.44 / ((VR1 + 2·R1)·C1) → ≈ 287 Гц … 72 кГц
- T_M = 1.1 · VR2 · C2
- N = ⌊T_M / T_A⌋ + 1,  f_OUT = f_A / N
